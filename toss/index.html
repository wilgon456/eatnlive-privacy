적용 범위

이 방침은 토스 앱 안에서 실행되는 먹고살기 미니앱에 적용됩니다. Google Play Android 앱의 개인정보처리방침과는 적용 범위가 다릅니다.

수집하지 않는 정보

먹고살기 운영자는 회원가입을 받지 않으며 이름, 전화번호, 이메일, 위치, 건강 프로필을 입력받지 않습니다. 별도의 자체 서버에 이용자 정보를 저장하지 않습니다.

사용자 식별키와 기기 저장

미니앱을 시작할 때 토스가 제공하는 익명 사용자 식별키를 받아 이 기기의 앱 저장소에 보관합니다. 같은 미니앱의 사용자를 구분하기 위한 값이며 운영자의 서버로 보내거나 로그에 기록하지 않습니다. 보관함에는 저장한 요리 ID 목록을 기기에 저장합니다. 저장 데이터는 앱 데이터가 삭제될 때 함께 삭제되며, 보관한 요리는 보관함에서 개별 삭제할 수 있습니다.

검색어와 선택한 항목

검색어와 선택한 증상·식품군은 앱이 실행되는 동안 메모리에서만 처리합니다. 검색 기록을 영구 저장하거나 URL, 분석 이벤트, 광고 요청 또는 외부 AI 서버로 보내지 않습니다.

이용 현황 분석

서비스 개선을 위해 토스의 공식 Analytics로 요리 화면 조회와 보관 성공 행동을 집계합니다. 운영자 코드가 전달하는 값은 고정된 행동명과 스키마 버전뿐이며 요리·증상 ID, 검색어, 보관 목록은 포함하지 않습니다. SDK는 익명 식별자 등 플랫폼 파라미터를 자동 처리할 수 있습니다. 플랫폼이 처리하는 항목과 보유 기간, 이용자 권리는 토스·앱인토스의 정책에 따릅니다.

배너 광고

토스 미니앱의 요리 화면에는 공식 TossAds 배너 광고가 표시될 수 있습니다. 운영자 코드는 광고 그룹 ID와 표시 옵션을 전달하며 검색어·증상 선택·보관 목록을 광고 SDK에 보내지 않습니다. 광고 SDK와 플랫폼의 데이터 처리는 토스·앱인토스의 정책에 따릅니다.

AI 이미지와 외부 출처

음식 사진과 증상 그림은 미리 만든 AI 예시 이미지이며 앱에 포함됩니다. 이용 중 검색어나 입력값을 AI 서비스로 전송하지 않습니다. 출처·개인정보 링크를 직접 누르면 외부 페이지가 열릴 수 있으며 해당 사이트가 IP 주소 등을 처리할 수 있습니다. 외부 사이트의 개인정보처리방침을 확인해 주세요.

이용자 권리와 문의

운영자가 별도로 보관하는 서버 기록은 없습니다. 기기에 저장된 보관함 항목은 앱에서 삭제할 수 있습니다. 토스 플랫폼이 처리하는 정보에 관한 권리 행사는 토스의 개인정보 관련 안내를 따릅니다. 먹고살기 운영자에게 이메일로 문의하면 문의 내용과 회신 주소를 답변에 필요한 범위에서 처리합니다.

방침 변경

새로운 데이터 처리 기능이 추가되면 적용 전에 앱 내 안내와 이 공개 방침을 갱신합니다.
